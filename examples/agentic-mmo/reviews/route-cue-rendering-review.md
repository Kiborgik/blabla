## Shared map layer and cleanup

Both SVG and Three adapters feed their projection functions into the same DOM effect layer. A safe positive route result creates one stationary receipt card and two marks keyed to its exact towns. It creates no token moving along the link, auto-pan, screen shake or synthetic departure/arrival state. Unanchored results create no guessed map element.

The layer is pointer-inert and its marks are decorative to accessibility tools. It does not install input handlers or take keyboard focus. Route cards use the existing collision-aware placement helper, accounting for panel, control, city-label and route-label rectangles; a crowded card may be hidden. Endpoint marks use the exact projected towns and viewport bounds. Actual layout/collision comfort still needs pixels.

The active layer enforces the same one/three maximum, including already visible ordinary effects, and shrinks its pool on a narrow resize. Duplicate event IDs do not create another card. Replaced anchors, expiration, explicit clearing and renderer disposal remove cards, endpoint marks and timers. Renderer disposal also preserves its existing observer/control/resource cleanup.

Rich and Cinematic add a short opacity entrance to the route card. Route-specific CSS suppresses the ordinary cinematic halo; endpoint marks remain stationary. Calm, effective reduced motion and the shared still class remove nonessential animation while retaining the same text and symbols. This is a reviewed implementation choice, not a complete accessibility-conformance claim.
