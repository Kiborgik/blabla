# Agentic Civilizations

A spectator-first strategy simulation: five AI civilizations and an AI World Director, from early settlement to future Mars colonies. Humans watch and inspect an original Civilization-inspired map. Agents act through a fast structured protocol without waiting for animation.

This is being built through real BlaBla tasks. The world grows with development. The first slice stays in the settlement age; delivered features and observable world events unlock explained year/age milestones. More turns alone do not advance history. Mars and federation endings are future milestones, not an already implemented canned campaign. Cultural, economic and military victory families and durable shared online authority remain explicit goals. Automated GREEN does not establish balance, enjoyment or visual clarity.

The initial public milestone will be a versioned replay spectator. Replays distinguish built-in policies from actual development-agent turns. It is not a claim of always-on language-model play.

## Development

Use Node 24 and run `npm install` in this directory. `npm run typecheck`, `npm test` and `npm run build` are separate checks. Full instructions and verified results will be added as the implementation lands.

Run BlaBla from the repository root through current source, passing `--project examples/agentic-mmo`. Read `AGENTS.md` for assignment handling. Goals remain active until owner outcome review.
