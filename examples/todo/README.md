# todo

A project with both layers, and the shortest path to an `OVERALL GREEN`. `project.bla` composes the
behavior contract [`../todo.bla`](../todo.bla) and the structure contract
[`todo-python.bla`](todo-python.bla), and carries the canonical verification profile.

```text
cd examples/todo
blabla status
blabla finish
```

[`test_app.py`](test_app.py) is an ordinary unit-test file for the same application: BlaBla
complements tests, it does not replace them.

[`../todo-go/`](../todo-go/README.md) satisfies the same behavior contract with a Go application, if
you want to see what the adapter boundary does and does not depend on.
