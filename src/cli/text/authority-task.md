A task is machine state: the orchestrator's record of one bounded assignment, held against the working tree. It never decides completion. Write scopes of every task not CLOSED or WITHDRAWN never overlap; reads may. task withdraw NAME --reason TEXT --model MODEL ends a task without credit and frees its scope; its changed paths stay challenged until restored or reconciled with task reconcile-withdrawal NAME PATH --successor TASK --model MODEL, where the successor must be CLOSED, and a reconciliation goes stale if the path changes again.
