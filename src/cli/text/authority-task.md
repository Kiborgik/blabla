A task is machine state: the orchestrator's record of one bounded assignment, held against the working tree. It never decides completion. Write scopes of every task not CLOSED or WITHDRAWN never overlap; reads may. task withdraw NAME --reason TEXT --model MODEL ends a task without credit and frees its scope; its changed paths stay challenged until restored or reconciled with task reconcile-withdrawal NAME PATH --successor TASK --model MODEL, where the successor must be CLOSED with current successful evidence at that moment; once recorded, a reconciliation stands while that same CLOSED successor record exists, so later changes to the path or the successor do not revive the residue.
