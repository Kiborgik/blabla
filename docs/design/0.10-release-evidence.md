# 0.10 release evidence

Released 6 October 2026. See [what changed](../../CHANGELOG.md#0100-2026-10-06) and the [working workflow](../agent-workflow.md).

## What the release establishes

Deterministic contracts, revision-bound task handoffs and experimental expert tooling. It does **not** establish faster development, better model judgment or live advisory benefit; a speed claim needs a declared matched comparison.

Self-hosting exposed one misleading signal: `status` suggested marking `goal::expert-loop-demonstrated-in-real-work` done once its contract expectations held, although its statement requires live results those contracts cannot show. `status` now routes such a goal to outcome review; the goal stays active, and stored states, JSON structure, verdicts and `OVERALL` are unchanged.

## Expert layer: experimental and unqualified

The transport, typed questions, selected packets, deterministic policy, replay and calibration machinery are implemented. Repository bindings remain shadow-only; no judgment is promoted.

Real Kev calibration completed but selected **no feasible policy**: it abstained on the development cases and missed justified nudges. A smaller rendering diagnostic reduced latency but did not establish useful drift detection. The holdout was not reopened to tune the failed policy. See [expert setup and qualification](../expert.md).

Actual installed-host observation/delivery and Luna/Jev provider use remain unverified where the [host report](0.10-host-capabilities.md) says so. Native cooperative between-turn support is not proof of always-on intervention. Deterministic GREEN never changes those capability limits.

## Release checks

Cargo, lockfile, plugin and citation versions agree on 0.10.0. The tag-triggered release workflow runs the product gate on Windows and Ubuntu before building and publishing the archives.
